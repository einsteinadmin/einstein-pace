The question: How should we use Pillars + Flywheel + PACe + OPSP in conjunction — and what should organize the Master Backlog?

What we have running right now:

  • 5 Strategic Pillars — Mover-First Economics · Op Ex · Financial Excellence · CX · Growth
  • Flywheel — 6 components, sub-flywheels in progress
  • PACe — 12 process boxes + 2 layers (this document)
  • OPSP — the plan everything serves
  • Master Backlog — 60+ rocks across all leaders, currently grouped by leader

Each framework surfaces priorities — sometimes the same ones, sometimes different. The result is a sprawling backlog that still needs triage regardless of which lens we look through.

My current hypothesis: these frameworks are diagnostic, not prioritizing. They help me see issues and opportunities; they don't decide what gets done first. The triage still happens through OPSP rocks + quarterly cadence — the frameworks feed that decision.

What I'd like from you:

  • Is that diagnostic-vs-prioritizing distinction right, or am I missing the point?
  • Should the Master Backlog be reorganized around one of these (Pillars feels the most natural)?
  • How do other Scaling Up companies use these tools in concert without sprawl?
  • Is there a precedence order — e.g., Pillars set direction → PACe finds process gaps → Flywheel checks customer flow → OPSP captures the rocks?
